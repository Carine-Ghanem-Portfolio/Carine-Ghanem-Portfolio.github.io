Deep learning pipeline for out-of-distribution detection in road scenes. Compared ERFNet (CNN) and EoMT (DINOv2 transformer) architectures. Evaluated post-hoc scoring methods including MSP, Max Logit, LogitNorm, and magnitude-aware regularization strategies across Fishyscapes and SMIYC benchmarks using AUPRC and FPR@95 metrics.

PyTorchDINOv2ViTERFNetCityscapesSMIYCFishyscapes

AI-powered chat application that ingests PDF documents, builds a knowledge graph via LightRAG, and generates structured 20,000-word handbooks through conversation. Uses Grok 4.1 for long-context generation with the LongWriter technique, Supabase for vector storage, and a Gradio/Streamlit chat interface for end-to-end document-to-handbook workflows.
